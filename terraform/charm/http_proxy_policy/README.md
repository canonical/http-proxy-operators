# Http-proxy-policy Terraform module

This folder contains a base [Terraform][Terraform] module for the http-proxy-policy charm.

The module uses the [Terraform Juju provider][Terraform Juju provider] to model the charm
deployment onto any machine environment managed by [Juju][Juju]. The http-proxy-policy charm is a
subordinate charm: it does not declare a `units` variable, since its unit count follows the
principal application it is related to.

## Module structure

- **main.tf** - Defines the Juju application to be deployed.
- **variables.tf** - Allows customization of the deployment. Also models the charm configuration,
  except for exposing the deployment options (Juju model UUID, channel or application name).
- **outputs.tf** - Integrates the module with other Terraform modules, primarily
  by defining potential integration endpoints (charm integrations), but also by exposing
  the deployed Juju application.
- **terraform.tf** - Defines the Terraform and Juju provider versions.

## Using http-proxy-policy base module in higher level modules

If you want to use `http-proxy-policy` base module as part of your Terraform module, import it
like shown below. Always pin the `?ref=` to a released tag or a commit hash: CC008 does not
allow floating references such as branches.

```text
data "juju_model" "my_model" {
  name = "my-model"
}

module "http-proxy-policy" {
  source = "git::https://github.com/canonical/http-proxy-operators//terraform/charm/http_proxy_policy?ref=tf-1.0.0"

  model_uuid = data.juju_model.my_model.uuid
  # (Customize configuration variables here if needed)
}
```

Create integrations, for instance:

```text
resource "juju_integration" "http-proxy-policy-juju-info" {
  model_uuid = data.juju_model.my_model.uuid
  application {
    name     = module.http-proxy-policy.application.name
    endpoint = module.http-proxy-policy.requires.juju-info.endpoint
  }
  application {
    name     = "http-proxy-configurator"
    endpoint = "juju-info"
  }
}
```

The complete list of available integrations can be found [in the Integrations tab][http-proxy-policy-integrations].
