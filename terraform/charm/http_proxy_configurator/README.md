# Http-proxy-configurator Terraform module

This folder contains a base [Terraform][Terraform] module for the http-proxy-configurator charm.

The module uses the [Terraform Juju provider][Terraform Juju provider] to model the charm
deployment onto any machine environment managed by [Juju][Juju].

## Module structure

- **main.tf** - Defines the Juju application to be deployed.
- **variables.tf** - Allows customization of the deployment. Also models the charm configuration,
  except for exposing the deployment options (Juju model UUID, channel or application name).
- **outputs.tf** - Integrates the module with other Terraform modules, primarily
  by defining potential integration endpoints (charm integrations), but also by exposing
  the deployed Juju application.
- **terraform.tf** - Defines the Terraform and Juju provider versions.

## Using http-proxy-configurator base module in higher level modules

If you want to use `http-proxy-configurator` base module as part of your Terraform module, import
it like shown below. Always pin the `?ref=` to a released tag or a commit hash: CC008 does not
allow floating references such as branches.

```text
data "juju_model" "my_model" {
  name = "my-model"
}

module "http-proxy-configurator" {
  source = "git::https://github.com/canonical/http-proxy-operators//terraform/charm/http_proxy_configurator?ref=http-proxy-configurator-tf-1.0.0"

  model_uuid = data.juju_model.my_model.uuid
  # (Customize configuration variables here if needed)
}
```

Create integrations, for instance:

```text
resource "juju_integration" "http-proxy-configurator-squid-forward-proxy" {
  model_uuid = data.juju_model.my_model.uuid
  application {
    name     = module.http-proxy-configurator.application.name
    endpoint = module.http-proxy-configurator.requires.http_proxy.endpoint
  }
  application {
    name     = "squid-forward-proxy"
    endpoint = "http-proxy"
  }
}
```

The complete list of available integrations can be found [in the Integrations tab][http-proxy-configurator-integrations].
